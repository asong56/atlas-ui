# Userscripts

Install via [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).

## bewlias.user.js

A clean, private, fast redesign of Bilibili's homepage. Removes ads, trackers, and visual noise. Adds a compact dock, glass top bar, and a recommendation feed with video preview on hover.

Bilibili changes its DOM regularly — if something breaks, check the selectors in the cleanup section first.

## github-enhancer.user.js

Small quality-of-life improvements for GitHub's UI.

## playback-speed.user.js

Persistent playback speed control that remembers your setting across page loads.
